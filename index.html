WG03 · Workshop

Engineering Implementation & Validation공학 구현과 검증

Workshop turns engineering knowledge into runnable software, algorithms and systems, and records how they are implemented and tested.Workshop은 공학 지식을 실행 가능한 소프트웨어, 알고리즘, 시스템으로 구현하고 구현과 시험 과정을 기록합니다.

Key activities주요 활동

  • AI model training and inferenceAI 모델 학습과 추론
  • Computer vision, sensor processing and sensor fusion컴퓨터 비전, 센서 처리, 센서 융합
  • Robotics software with ROS/ROS2 and Edge AI implementationsROS/ROS2 로봇 소프트웨어와 Edge AI 구현
  • Reproducible environments and benchmark scripts재현 가능한 실행 환경과 벤치마크 스크립트

Scope of work주요 관리 대상

  • Reference Implementations
  • Deep Learning Examples
  • Sensor Fusion
  • Benchmark Scripts
  • Reproducibility Collections

A public repository does not by itself mean that execution or performance has been verified.공개 저장소가 있다는 사실만으로 실행이나 성능이 검증되었다는 뜻은 아닙니다.
